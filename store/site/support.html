Support

Questions, bug reports and feature requests go to the issue tracker on GitHub. Please do not post API keys or log contents there.

Getting connected

  1. In SigNoz, open Settings, then Service Accounts, and create an account with the Viewer role.
  2. Create an API key for it and copy the key.
  3. In PocketOps, enter your SigNoz address (for example signoz.example.com) and paste the key.

Common problems

  • "Key rejected": the key was revoked, or belongs to a different SigNoz instance than the address you entered.
  • Cannot reach the server: your phone has to be able to reach the address, so a server on a private network needs a VPN or to be on the same Wi-Fi. Plain http is accepted only for private-network addresses; anything on the internet needs https.
  • Old data on screen: when requests fail, a banner says so and shows how old the data is.
