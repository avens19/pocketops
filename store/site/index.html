A few things to know

Before you head out.

Do I need an existing SigNoz instance?

Yes. PocketOps is a mobile client for SigNoz. It connects to your existing server with a service-account API key; it does not host or collect telemetry for you.

Can PocketOps change anything on my server?

It can create and update shared saved views when your API key has permission. With a Viewer-role key, you can browse your telemetry without those save controls.

Does every dashboard panel work?

The viewer supports builder and formula queries in time-series charts, stacked bars, tables, numbers, and text panels. Some advanced query types and web-specific presentation settings are not supported. Dashboard editing stays in SigNoz.

Is this an official SigNoz app?

No. PocketOps is an independent, open-source app by Andrew Ovens. It is not affiliated with or endorsed by SigNoz.
